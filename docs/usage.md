# WordSearch 1.6.0 · 游戏鼠标词典

Windows 桌面工具，适合在《极乐迪斯科》中边玩边查词。鼠标指向英文单词后按取词键，旁边会出现参考 Lookupper 2.0.6 制作的深灰词卡：细分隔线、单词和双发音按钮、收藏按钮、音标词性、中英释义、折叠上下文。游戏中的目标词也会标黄。长释义和词形参考按需展开。内置 ECDICT 离线英汉双解词典，共 770,611 条词条，普通查词不需要 API Key。

## 启动与查词

下载单文件版 `WordSearch-1.6.0-win64.exe`，双击即可运行。不需要解压或安装 Python，也不需要同目录的 `_internal` 文件夹。程序会自动将内置依赖和词典释放到系统临时目录，启动时请稍等。

游戏使用无边框窗口或窗口模式。每按一次取词键查一次；移动鼠标或停在其他词上不会换词，也不会重新打开已关闭的词卡。

| 操作 | 默认快捷键 |
|---|---|
| 鼠标指向单词，立即取词 | Ctrl+D |
| 框选单词、短语或对白 | Ctrl+Shift+D |
| 设置固定对白区域 | Ctrl+Alt+D |
| 收起词卡 / 取消框选 | Esc |

第一次可框选右侧对白栏作为固定区域。查词只提取目标词所在段落，按间距、说话者和选项编号分段；下方选项不混入旁白。框选多段时，原文和译文保留段落。更改游戏分辨率或窗口位置后，重新设定区域。没有固定区域时，读取鼠标周围的文字。

词卡顶部可以拖动。点击单词右侧的「收藏」加入生词本收藏，再点一次取消；收藏按单词计算，以后再查到同一个词仍显示「已收藏」，AI 查询进行中也可以点。点击词卡外空白处自动收起，卡内按钮、选字和输入正常使用。右键词卡可「修正原文」（改正 OCR 识别的单词或段落后重新查询，可查看取词截图）、固定位置、打开生词本或设置。识别失败时词卡显示输入框，可直接输入单词。

单词旁的两个按钮分别优先选择英式、美式系统语音；未安装对应口音时使用已有英语语音。展开「上下文」后可朗读原句，并显示来源应用。发音使用 Windows SAPI，不需要网络。

游戏取词优先使用 Windows Graphics Capture，关闭系统光标捕获并保持鼠标原位；已在《极乐迪斯科》画面验证。该能力需要 Windows 10 2004 或更新版本。接口不可用时回退屏幕截图，仍保持鼠标原位；游戏自行绘制的光标和艺术字体可能影响 OCR，单词和原句可手动修正。截图仅保存在内存。

## AI 语境与自选 API

首次语境翻译与当前词的中文标黄合并为一次 AI 请求，对应片段返回后即可标黄。对齐使用当前选中的原文位置；无法确定时保留译文。内部标记不显示，也不保存到生词本。最近 128 个对齐结果在当前运行期间缓存；同段换词保留译文，只在新词没有对齐缓存时补一次请求。高亮不改变字体和分段。

普通查词先显示本地释义。配置 API 后默认自动翻译当前段落，上方只显示译文，同一段对白换词复用译文。翻译提示词禁止标题、词义说明和 OCR 评论；单词解释与追问使用各自提示词。《极乐迪斯科》特化使用少量[已核实译名](disco-elysium.md)，只对当前原文出现的术语提供参考。自动翻译与单词查词分别运行。上方「语境翻译」旁的星形按钮可手动翻译或重试，下方词典标题旁的星形按钮解释单词在当前对白中的含义；两分区分别保留结果。点击「ECDICT」可返回离线释义。单词 AI 回答完成后点击「解释」展开追问输入框，查询中可点击停止图标。

在生词本右上角齿轮、托盘菜单或词卡菜单打开设置。点击「服务」旁的 + 选择预设（DeepSeek、OpenRouter、硅基流动、Ollama 或 Chat Completions 兼容的自定义接口），填写 API Key、地址和模型名后点击「保存」；可以保存多个服务，下拉框切换当前服务。

地址可以填写基础地址，例如 `https://api.deepseek.com/v1`，或完整 `/chat/completions` 地址。模型名可手动填写；模型旁的刷新按钮读取模型列表，需要服务支持 `/models`。「测试连接」会发送一条真实请求，消耗所选服务的少量额度。

Ollama 本地预设使用 `http://localhost:11434/v1`，不需要 Key，模型名填写本机已安装的模型。

使用 DeepSeek 官方接口的 `deepseek-flash` 或 `deepseek-v4` 系列时关闭思考模式，缩短查词等待；其他自定义接口不附加该参数。参数依据 [DeepSeek 官方文档](https://api-docs.deepseek.com/guides/thinking_mode/)。

可在设置关闭默认开启的「自动翻译段落」，之后仍可点击星形按钮手动翻译。自动翻译使用所选服务的额度，最近 64 段原文在当前运行期间缓存，服务、模型、凭据或游戏来源改变后分别缓存。新记录保留游戏来源，从生词本重新查询仍可使用对应译名参考。没有配置 API 时显示未配置状态，不发出请求。还可启用「取词后 AI 解释」，让快捷键或框选取词同时请求单词语境释义；该项默认关闭。

Key 使用 Windows DPAPI 按当前登录用户加密保存，不包含在历史记录或 CSV 中。AI 只接收当前显示的词和文字上下文，截图不发送给 AI；提示词要求根据当前文本解释并避免后续剧情信息。本工具不提供共享 Key 或 AI 额度。

## 生词本与数据

查过的单词都会保存到生词本，同一个词只显示最近一次。单击托盘图标打开生词本：顶部输入框既能搜索，也能按回车在词卡中查询新词；双击单词重新打开词卡，点右侧星标收藏，右键可删除。右上角 ⋯ 可导出 CSV 或清空。导出包括词、原句、解释、服务、模型、收藏状态和时间，使用 UTF-8 BOM，可用于 Excel 或 Anki 导入。

设置、历史和日志保存在 `%LOCALAPPDATA%\WordSearch`。启动后程序在托盘运行并提示取词快捷键；关闭窗口或词卡只会收起。托盘右键菜单提供框选、设定对白区域、生词本、设置和退出。

词典来自 [skywind3000/ECDICT](https://github.com/skywind3000/ECDICT)，按 MIT 许可证使用。完整许可证和固定数据版本随词典内置于 EXE 的 `assets/dictionary`，运行时释放到临时目录；其他依赖许可证见仓库的 `THIRD_PARTY_NOTICES.md`。

## 系统与开发

Windows 10 1809 及以上 / Windows 11 x64，需安装英语 OCR 语言组件。若缺少英语识别器，在 Windows 设置的「语言和区域」安装英语语言包及基本输入功能。

开发使用 Python 3.13 x64：安装 `requirements.txt` 后运行 `python main.py`。首次准备词典执行 `python tools/prepare_dictionary.py`，会下载上游 ECDICT 固定版本并生成本地数据库。

打包执行 `python -m PyInstaller --clean --noconfirm WordSearch.spec`，生成的单文件程序是 `dist/WordSearch.exe`。

快捷键被占用时，在设置修改；浮窗不可见时，将游戏改为无边框窗口或窗口模式；艺术字体识别不准时，框选文字或右键词卡修正原文。
