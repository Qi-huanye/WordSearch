# WordSearch 1.4.0 · 游戏鼠标词典

Windows 桌面工具，适合在《极乐迪斯科》中边玩边查词。鼠标在英文单词上停留约 0.65 秒，旁边会出现参考 Lookupper 2.0.6 制作的深灰词卡：细分隔线、橙色书签、单词和双发音按钮、音标词性、中英释义、折叠上下文。游戏中的目标词也会标黄。长释义和词形参考按需展开。内置 ECDICT 离线英汉双解词典，共 770,611 条词条，普通查词不需要 API Key。词典名称和内容对应实际数据来源，未提供的等级信息不显示。

## 启动与查词

解压便携版的整个目录，双击 `WordSearch.exe`。不需要安装 Python；请保留同目录的 `_internal` 文件夹。

游戏使用无边框窗口或窗口模式。默认只在《极乐迪斯科》处于前台时自动悬停取词。也可以在设置关闭自动悬停，使用快捷键取词。

| 操作 | 默认快捷键 |
|---|---|
| 鼠标停留在游戏英文单词上 | 自动取词 |
| 鼠标指向单词，立即取词 | Ctrl+D |
| 框选单词、短语或对白 | Ctrl+Shift+D |
| 设置固定对白区域 | Ctrl+Alt+D |
| 收起词卡 / 取消框选 | Esc |

第一次可框选右侧对白栏作为固定区域。查词只提取目标词所在段落，按间距、说话者和选项编号分段；下方选项不混入旁白。框选多段时，原文和译文保留段落。更改游戏分辨率或窗口位置后，重新设定区域。没有固定区域时，读取鼠标周围的文字。

词卡顶部可以拖动，右上角书签收藏当前条目。右键词卡空白处可编辑原文、打开生词本或设置、返回本地词典、固定位置或收起。固定词卡暂停自动悬停。首次打开可直接输入单词。管理窗口只保留查词、生词本与设置，操作提示在鼠标悬停时显示。

单词旁的两个按钮分别优先选择英式、美式系统语音；未安装对应口音时使用已有英语语音。展开「上下文」后可朗读原句，并显示来源应用。发音使用 Windows SAPI，不需要网络。

截图前短暂移开鼠标，减少游戏光标遮挡，随后恢复；用户自行移动鼠标时不会强行恢复。OCR 可能误识别艺术字体，单词和原句都可手动修正。截图仅保存在内存。

## AI 语境与自选 API

普通查词先显示本地释义。配置 API 后默认自动翻译当前段落，上方只显示译文，同一段对白换词复用译文。翻译提示词禁止标题、词义说明和 OCR 评论；单词解释与追问使用各自提示词。《极乐迪斯科》特化使用少量[已核实译名](disco-elysium.md)，只对当前原文出现的术语提供参考。自动翻译与单词查词分别运行。上方「语境翻译」旁的星形按钮可手动翻译或重试，下方词典标题旁的星形按钮解释单词在当前对白中的含义；两分区分别保留结果。点击「ECDICT」或在右键菜单选择「本地词典」可返回离线释义。单词 AI 回答完成后点击「解释」展开追问输入框，查询中可点击停止图标。

在词卡右键菜单选择「设置」，选择服务预设，填写自己的 API Key、API 地址和模型名，然后点击「保存」。支持 DeepSeek、OpenRouter、硅基流动及 Chat Completions 兼容的自定义接口；可以保存多个服务配置。

API 地址可以填写基础地址，例如 `https://api.deepseek.com/v1`，或完整 `/chat/completions` 地址。模型名可手动填写；「读取模型」需要服务支持 `/models`。「测试连接」会发送一条真实请求，消耗所选服务的少量额度。

Ollama 本地预设使用 `http://localhost:11434/v1`，不需要 Key，模型名填写本机已安装的模型。

使用 DeepSeek 官方接口的 `deepseek-flash` 或 `deepseek-v4` 系列时关闭思考模式，缩短查词等待；其他自定义接口不附加该参数。参数依据 [DeepSeek 官方文档](https://api-docs.deepseek.com/guides/thinking_mode/)。

可在设置关闭默认开启的「自动语境翻译」，之后仍可点击星形按钮手动翻译。自动翻译使用所选服务的额度，最近 64 段原文在当前运行期间缓存，服务、模型、凭据或游戏来源改变后分别缓存。新记录保留游戏来源，从生词本重新查询仍可使用对应译名参考。没有配置 API 时显示未配置状态，不发出请求。还可启用「快捷键取词后自动查询 AI」，让手动快捷键或框选查询同时请求单词语境释义；该项默认关闭。

Key 使用 Windows DPAPI 按当前登录用户加密保存，不包含在历史记录或 CSV 中。AI 只接收当前显示的词和文字上下文，截图不发送给 AI；提示词要求根据当前文本解释并避免后续剧情信息。本工具不提供共享 Key 或 AI 额度。

## 生词本与数据

本地词典查询和成功的 AI 查询都会保存。支持收藏、搜索、重新打开、删除、清空和导出 CSV。导出包括词、原句、解释、服务、模型、收藏状态和时间，使用 UTF-8 BOM，可用于 Excel 或 Anki 导入。

设置、历史和日志保存在 `%LOCALAPPDATA%\WordSearch`。关闭管理窗口或词卡会收起到托盘；单击托盘图标重新打开词卡，右键菜单提供设置和退出。

词典来自 [skywind3000/ECDICT](https://github.com/skywind3000/ECDICT)，按 MIT 许可证使用。完整许可证和固定数据版本保存在 `_internal/assets/dictionary`，其他依赖许可证见 `THIRD_PARTY_NOTICES.md`。

## 系统与开发

Windows 10 1809 及以上 / Windows 11 x64，需安装英语 OCR 语言组件。若缺少英语识别器，在 Windows 设置的「语言和区域」安装英语语言包及基本输入功能。

开发使用 Python 3.13 x64：安装 `requirements.txt` 后运行 `python main.py`。首次准备词典执行 `python tools/prepare_dictionary.py`，会下载上游 ECDICT 固定版本并生成本地数据库。

打包执行 `python -m PyInstaller --noconfirm WordSearch.spec`，交付目录是 `dist/WordSearch`。

快捷键被占用时，在设置修改；浮窗不可见时，将游戏改为无边框窗口或窗口模式；艺术字体识别不准时，框选文字或编辑原文。
